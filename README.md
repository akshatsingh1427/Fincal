## 📌 About

**FinCal** is an interactive, educational financial calculator built for everyday investors. It covers SIP, Lump Sum, Goal Planning, and Fund Comparison with live charts, real-time calculations, and concept explainers — making mutual fund literacy simple and visual for people with no finance background.

---

## ✨ Features

| Module | Description |
|--------|-------------|
| 🚀 **SIP Calculator** | Monthly investment growth with animated bar charts |
| 💎 **Lump Sum** | One-time investment compounding over time |
| 🎯 **Goal Planner** | Reverse-calculates the SIP or lump sum needed to hit your goal |
| ⚖️ **Fund Compare** | Risk-vs-reward table with a radar chart across fund types |
| 📚 **Learn** | Six key concepts with formulas — NAV, CAGR, Compounding, and more |
| 🗺️ **Rupee Journey** | A visual story of how money grows, and the true cost of delay |
